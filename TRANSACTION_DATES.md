# Дата совершения транзакции

`created_at` — время создания записи. `occurred_at` — дата и время совершения
операции; месячный баланс учитывает именно её и границы месяца по МСК (UTC+03:00).

`GET /api/transactions/balance?month=9` возвращает баланс за сентябрь текущего
года по МСК. `month` — число от 1 до 12. Если параметр отсутствует, используется
текущий месяц. Неверный номер или формат месяца возвращает HTTP 422.

При `POST /api/transactions` можно передать `occurred_at`, например
`"2026-10-05T18:30:00+03:00"`. Если поле отсутствует, используется текущее время МСК.
Значение без смещения считается временем МСК; значение со смещением переводится
в МСК. Ответ всегда содержит `occurred_at` со смещением `+03:00`.

Для изменения даты: `PATCH /api/transactions/{id}` с телом
`{"occurred_at": "2026-09-30T23:30:00+03:00"}`. Нужны авторизация и заголовок
`X-CSRF-Token`, как для остальных изменяющих запросов. Менять можно только свои
транзакции. Пустая дата и неизвестные поля в PATCH отклоняются.

SQLite хранит `occurred_at` как местное время МСК без timezone. В миграции `0005`
старые `created_at` копируются в `occurred_at` без изменения часов и трактуются
как МСК: исходный timezone и фактическая дата операции ранее не сохранялись.
Ошибочную дату старой операции можно исправить через PATCH.

Обновление базы: `.\.venv\Scripts\python.exe -m alembic upgrade head`.
